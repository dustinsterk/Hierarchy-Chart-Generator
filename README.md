# Hierarchy Chart Generator

This utility was created to allow for easy manipulation of any heirachial dataset in visual form.  The main use case was to create a tool to allow for quick org chart planning.
Once you load a .csv or create a new chart, press the purple "Edit Layout" button to start editing...
<img width="1720" height="783" alt="Main Screen" src="https://github.com/user-attachments/assets/10ff5a60-cb4d-4b8c-81ce-251a4b3d4cb0" />

Features include:
* Creation of a new chart from a blank canvas.
* Loading data via .csv data file (see example dataset included or instructions on main page for format).
* Node font/size formatting for entire tree.
* Node color formatting for the whole tree or individual nodes (with multiselect capabilities).
  * Multi select with either: ctrl or command OR a long mouse click when selecting a node in the canvas
* Ability to show and hide different levels and leaf/non-leaf nodes.
* Quick updates of both node data and parent selection.
* Adding and Deleting nodes.
* Auto arranging nodes.
* Visual parent node indicator to show the number of direct reports.
* Calculation of total number of decendant nodes when a parent node is highlighted (found in Node Details).
* Zooming and repositioning capabilites within the canvas.
* Exporting chart in .svg format
* Saving chart back into .csv format (positions and colors included).
