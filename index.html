Hierarchy Chart Generator

Upload a CSV file to visualize your hierarchy or click 'Create New Graph' to start with an empty chart.

Click to upload or drag and drop CSV file
Create New Graph

CSV Format:

Your CSV should have columns: name, parent_id

Note: The system uses name as the unique identifier. parent_id should match the full name of the parent node.

Additional metadata columns are supported: title, location, phone, email, etc.

parent_id should be empty or "null" for root nodes

Example CSV 
name,parent_id,title,location,phone,email
CEO,,Chief Executive Officer,New York,555-0100,ceo@company.com
VP Engineering,CEO,Vice President,San Francisco,555-0101,vpeng@company.com
VP Sales,CEO,Vice President,Chicago,555-0102,vpsales@company.com
Engineering Manager,VP Engineering,Manager,San Francisco,555-0103,engmgr@company.com
QA Manager,VP Engineering,Manager,San Francisco,555-0104,qamgr@company.com
Sales Manager,VP Sales,Manager,Chicago,555-0105,salesmgr@company.com

Edit Mode Features:

  • Click and drag nodes to reposition them
  • Dragging nodes does not change parent-child relationships
  • Select a node to see resize handles in the corners
  • Drag resize handles to change node size
